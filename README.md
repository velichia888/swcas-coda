# Saturday Women's Caring & Sharing (CoDA)

Website and companion app for a women's Co-Dependents Anonymous home group in Tempe, AZ.
Saturdays 10:15 AM (Arizona time), Church of the Resurrection, Room #3, 3201 S Evergreen Rd, Tempe, AZ 85282.

- `index.html`: home page (meeting info, directions, newcomers, readings links)
- `docs/newcomers.html`: first-meeting page
- `app/`: companion app (recovery counter, check-in, meeting countdown, add to calendar). Data stays on the phone.
- `assets/`: logo, shared styles (`style.css`), dark mode (`theme.js`), quick exit and next-meeting strip (`ui.js`)

CoDA literature is copyrighted, so the site links to coda.org instead of copying it.
This site is kept by group members and is not an official site of Co-Dependents Anonymous, Inc.
